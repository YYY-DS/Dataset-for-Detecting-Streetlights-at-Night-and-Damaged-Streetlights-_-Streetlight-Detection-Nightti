## 数据集概述

本数据集专注于**夜间场景下路灯及损坏路灯的视觉检测与识别**，服务于市政设施巡检、道路照明管理及智慧城市治理。数据涵盖正常路灯与损坏路灯两类目标，适配夜视巡检、路灯故障排查及自动化资产管理等应用。

## 数据三要素解析

**类别与目标覆盖**
*   数据集定义 **2** 类目标：**正常路灯**与**损坏路灯**，聚焦于夜间路灯状态识别。
*   类别设置直接服务于“亮灯/灭灯”状态判别，辅助市政照明管理。
*   正常路灯标注数远多于损坏路灯（26860 vs 1060），反映了正常路灯在夜间场景中的主导地位，同时也提示存在**类别不平衡**问题。

**数据规模与场景**
*   图像总量约 **5500** 张，规模较为充足，能支撑检测模型的稳健训练。
*   数据专为**夜视场景**采集，图片清晰，适合夜间路灯检测研究。
*   夜间场景光照条件特殊，路灯作为发光体，与背景形成强烈对比，为模型提供了明确的视觉线索。

**格式与结构**
*   采用通用 **YOLO 格式**（txt），每张图像对应一个同名标签文件，包含类别 ID 与归一化边界框坐标，可直接接入 YOLOv5、YOLOv8 等主流检测框架。
*   图像与标签一一对应，数据结构规范，即拿即用。

## 知识普及：夜间路灯检测的技术要点

*   **强光与眩光干扰**：夜间路灯作为高亮光源，可能产生眩光、光晕，影响边界定位。模型需学习光晕下的路灯轮廓特征。
*   **类别不平衡处理**：损坏路灯样本远少于正常路灯，训练时可采用**类别加权损失**、**Focal Loss** 或**过采样**策略，提升对损坏路灯的召回率。
*   **小目标检测**：远距离路灯在图像中尺寸较小，需采用高分辨率输入或多尺度特征融合策略。
*   **背景复杂性**：夜间场景中，其他光源（如车灯、店铺招牌、窗户灯光）可能被误判为路灯，模型需依赖路灯的形态（杆状结构、固定位置）进行区分。
*   **应用闭环**：检测结果可结合GPS信息，生成路灯故障分布图与维修工单，辅助市政照明维护调度，提升城市夜间照明质量与安全性。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 2
names: ['正常路灯', '损坏路灯']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
